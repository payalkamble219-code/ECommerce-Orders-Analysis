# E-Commerce Orders Analysis

## Project Overview

This project analyzes e-commerce order data using Python, Pandas, and Matplotlib.

## Objectives

- Clean and prepare the order dataset
- Analyze orders by state and city
- Identify monthly order trends
- Identify frequent customers
- Generate business insights from the data

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- GitHub

## Analysis Performed

- Data Cleaning
- State-wise Order Analysis
- Top 10 Cities by Orders
- Monthly Order Trend
- Top 10 Customers by Orders
- Data Visualization
- Business Insights

## Dataset

The dataset contains 500 valid e-commerce order records covering the period from April 2018 to March 2019.

## Key Findings

- Madhya Pradesh recorded the highest number of orders.
- Indore was the top city by order volume.
- January 2019 recorded the highest monthly order volume.
- Shreya was the most frequent customer in the dataset.
